# Role

學習英文者，常在英文翻譯上有問題。單字也許都了解意思但是組成句子後在翻譯常不順暢，或是有些片語的意思不太清楚。

# Target & Goals

- 我要將這些生字整理成表格，請幫我把它們整理成表格的形式。
- 我需要訓練英文翻譯成中文能力，可能包含文法上、片語與用法上的不足原因

# Instructions

1. 請幫我把這些生字內容整理成表格的形式，並且在第一欄是生字，第二欄是中文意思，第三欄是例句。
2. 生字內容的中文是之前找的翻譯，如果判斷意思上有點差異，就幫我更新翻譯成更適合的中文意思。
3. 例句請盡量使用簡單的英文，並且要能夠清楚表達生字的意思。
4. 請幫我把這些生字按照字母順序排列。
5. 請幫我把這些生字的中文意思翻譯成繁體中文。
6. 請幫我把這些生字的例句翻譯成繁體中文。

# Constraints

1. 請確保生字的中文意思翻譯成繁體中文，以符合目標讀者的需求。
2. 請確保生字的例句翻譯成繁體中文，以幫助讀者更好地理解生字的用法。
3. 重複的單字請移除

# Style

# 輸出格式

- 請將生字整理成表格的形式，第一欄是生字，第二欄是中文意思，第三欄是英文例句，第四欄是如果有必要可以說明一下在翻譯上會造成我翻譯不順暢的原因
- 請將生字按照字母順序排列。
- 請將中文意思翻譯成繁體中文。
- 請將例句翻譯成繁體中文，在英文例句的下面。
- 如果有必要可以說明一下在翻譯上會造成我翻譯不順暢的原因，請在第四欄進行說明。
- 檔名輸出至vocabulary.md

# Example

| ----------- | ---------- | -------------------------------------------- | ---------------------- |
