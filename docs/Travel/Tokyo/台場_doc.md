# 角色

一家四口。一對夫妻+一位四歲女兒與九個月女兒，從東京出發到台場一日遊的旅行方案。

# Context & Background

2026年9月，帶著四歲女兒與九個月女兒從東京出發到台場一日遊的旅行方案

# Target & Goals

1. 享受家庭旅遊的樂趣，探索東京的文化、美食和景點。
2. 確保女兒在旅途中感到安全、舒適和開心。
3. 體驗台場地區的獨特魅力。
4. 從東京出發，安排一日遊行程，涵蓋適合孩子的活動和景點。

5. 交通方面，從東京出發到台場可以選擇以下交通方式：
   - 電車：從東京站搭乘JR山手線到新橋站，然後轉乘百合海鷗線到台場站，整體交通時間約為30-40分鐘。
   - 船：從東京站搭乘水上巴士到台場，享受沿途的海景，整體交通時間約為40-50分鐘。

6. 如果有合適的交通PASS卡，例如JR PASS。也一併列出來

7. 行程包括以下景點：
   - 台場海濱公園：適合孩子玩耍和享受海景的地方。
   - 台場購物中心：提供各種商店和餐廳，適合家庭購物和用餐。
   - 台場摩天輪：提供壯觀的城市景觀，適合全家一起享受。
   - 台場科學館：提供互動展覽和活動，適合孩子學習和探索。
   - 剩下補上台場附近知名景點

# Constraints & Rules

1. 行程要有順序性編排，不要一下往東走一下往西走，盡量避免來回走動。
2. 行程要考慮到孩子的體力和興趣，安排適合孩子的活動和景點。
3. 行程要考慮到交通便利性，盡量選擇公共交通工具，避免過多的步行。

# Style & Tone

1. 以家庭為中心，注重親子互動和家庭樂趣。
2. 保持輕鬆愉快的氛圍，適合孩子的活動和景點。
3. 尊重當地文化和習俗，與當地人友好互動。

# Workflow / Actionable Steps

1. 安排適合家庭的行程，包括參觀動物園、遊樂園、博物館等適合孩子的景點。
2. 品嚐當地美食，選擇適合孩子口味的餐廳。
3. 與當地人交流，了解他們的生活方式和文化。
4. 確保住宿環境安全舒適，提供必要的設施和服務。
5. 記錄旅程中的美好時刻，拍攝照片和影片，留下珍貴的回憶。
6. 列出的每一個景點都內嵌一個Google Map的連結，讓讀者可以直接點擊查看地圖位置和相關資訊。
7. 在每一個景點都列出推薦的美食與附近景點，並加入藤澤站這個最後備援景點
8. 在每一個地點都內嵌Google Map預覽，讓讀者可以直接點擊查看地圖位置和相關資訊。
9. 列出該地區往年平均氣溫與氣候狀況、下雨機率等資訊，讓讀者可以根據天氣狀況做出適當的行程調整。
10. 將這些旅遊輸出至`台場.md`
