# Vue-i18n 在 Vue 3 專案中的使用指南

這篇指南將以 `vue3-wrt-project` 為例，說明如何設定與使用 `vue-i18n` 來實作多語系功能，並包含切換語言的動作。

## 1. i18n 設定檔 (`i18n.ts`)

在專案中，我們會在 `i18n.ts` 中初始化 `vue-i18n` 實體，並自動載入 `locales` 資料夾下的翻譯檔。

```typescript
import { createI18n } from 'vue-i18n';

// 定義翻譯訊息型別
type Messages = Record<string, string>;

// 自動載入 ./locales 下所有 ts 檔案
const modules = import.meta.glob<{ default: Messages }>('./locales/*.ts', { eager: true });

// 將模組轉成 messages 物件
const messages: Record<string, Messages> = Object.fromEntries(
    Object.entries(modules).map(([path, module]) => {
        // 從檔名中取出 locale (例如: EN, TW)
        const locale = path.match(/\/([a-zA-Z_-]+)\.ts$/)![1];
        return [locale, module.default];
    }),
);

const i18n = createI18n({
    legacy: false, // Vue 3 Composition API 必須設為 false
    locale: 'TW', // 預設語言
    fallbackLocale: 'EN', // 備用語言
    messages,
});

export default i18n;
```

## 2. 在元件中使用翻譯 (`Login.vue` 範例)

在 Vue SFC (單一檔案元件) 中，我們可以使用 Composition API 的 `useI18n` 來取得 `t` 函數，藉此對文字進行翻譯。

```vue
<template>
    <!-- 使用 t('翻譯鍵值') 來取得對應的翻譯文字 -->
    <div class="login-title">{{ t('LOGIN') }}</div>
    <div class="login-desc">{{ t('SIGNIN_TITLE') }}</div>
    
    <q-input :label="t('USERNAME')" />
</template>

<script setup lang="ts">
import { useI18n } from 'vue-i18n';

// 取出 t 函數
const { t } = useI18n();
</script>
```

## 3. 切換語言 (`useChangeLanguage.ts` 範例)

如果要實作切換語言的功能，可以直接修改 `useI18n({ useScope: 'global' })` 所回傳的 `locale.value`。
在 `vue3-wrt-project` 的實作中，還會搭配呼叫 API 更新後端路由器的設定檔 (nvram)。

```typescript
import { useI18n } from 'vue-i18n';
import { setNvram } from '@/api/nvram.api';

export default function useChangeLanguage() {
    // 取得全域的 locale 設定
    const { locale } = useI18n({ useScope: 'global' });
    
    const changeLanguage = (langCode: string) => {
        // 1. 更新前端 Vue-i18n 語言
        locale.value = langCode;
        
        // 2. 將語系設定同步至後端 API (路由器系統)
        setNvram({ action_mode: 'apply', preferred_lang: langCode });
    };

    return { changeLanguage };
}
```

### 如何在元件中觸發語言切換？

在元件中引入 `useChangeLanguage` 即可：

```vue
<template>
  <button @click="changeLanguage('EN')">English</button>
  <button @click="changeLanguage('TW')">繁體中文</button>
</template>

<script setup lang="ts">
import useChangeLanguage from '@/composables/useChangeLanguage';

const { changeLanguage } = useChangeLanguage();
</script>
```
